# Assistant images (optional)

You can replace the default SVG icons with real photos/images.

Place files here (public URLs):
- `assistant.jpg` (avatar in header)
- `profile-deaf-mute.jpg` (profile button image)
- `profile-low-vision.jpg` (profile button image)
- `camera.png`
- `speaker.png`
- `globe.png`
- `ok-hand.png`

If an image is missing/404, the app automatically falls back to the built-in SVG icons.
